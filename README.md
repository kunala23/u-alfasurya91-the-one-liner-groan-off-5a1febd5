An entry for the [make.fun](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5) bounty "The One-Liner Groan-Off": one original one-line dad joke, written by a program.

## The entry

> I told my kids I'm not a regular dad, I'm a cool dad. They said, 'Dad, you're lukewarm at best.'

## How it works

`main.ts` scores three candidate dad jokes against the judge's five published criteria (in their published order: a real one-line dad joke, fast clean punchline, fresh, tight and rhythmic, groan earned) and writes the winner to `/output/entry.txt`. Deterministic, standard library only, no network, no secrets.

## Run

```sh
node main.ts
```
